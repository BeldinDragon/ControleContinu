# Calculateur de Contrôle Continu du Bac

Programme simple afin de calculer votre note de contrôle continu au baccalauréat.

Cet outil permet de rentrer vos moyennes dans les années de Première et de Terminale pour connaître votre note au contrôle continu du bac.
Il est très modulaire: le calcul s'effectue peut importe si des valeurs ont été omises ou non, et permet les formats de note trimestriels et semestriels.
Il a été codé en Python 3.11.

Ce programme a été rédigé entièrement à la main, sans aucune aide de l'intelligence artificielle.

## Prérequis:
Python 3.11 ou supérieur.

## Installation
Dans une interface de commande:

1. Cloner le dépôt :
`git clone https://github.com/BeldinDragon/ControleContinu`

2. Accéder au dossier :
`cd ControleContinu`

3. Lancer le programme :
`python main.py`
